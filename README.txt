PUBLICAR EN VERCEL
1. Creá un repositorio nuevo en GitHub.
2. Subí TODOS los archivos de esta carpeta manteniendo la carpeta assets.
3. Entrá a Vercel y elegí Add New -> Project.
4. Importá el repositorio de GitHub.
5. Framework Preset: Other.
6. Build Command: dejar vacío.
7. Output Directory: dejar vacío.
8. Deploy.
